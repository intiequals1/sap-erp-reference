# sap-erp-reference
Offenes SAP/ERP-Lern- und Referenzprojekt: ein nachvollziehbarer Prozess von Stammdaten bis Buchung und Reporting. Mitarbeit über Issues und Pull Requests.

## Aufgaben

Öffentliche Aufgaben stehen als [Issues](https://github.com/intiequals1/sap-erp-reference/issues) bereit. Alle Aufgaben des Labors sammeln das [Projektboard](https://github.com/users/intiequals1/projects/6) und die [Aufgabenübersicht](https://github.com/intiequals1/digitalpath-site/issues/1).

- [#1 Referenzprozess: einen kleinen Ablauf und minimale Stammdaten abgrenzen](https://github.com/intiequals1/sap-erp-reference/issues/1)
- [#2 Synthetischen Beispieldatensatz und erwartetes Buchungs-/Reportingergebnis beschreiben](https://github.com/intiequals1/sap-erp-reference/issues/2)
- [#3 Reproduzierbaren Prozessdurchlauf mit Ergebnis und Grenzen dokumentieren](https://github.com/intiequals1/sap-erp-reference/issues/3)

Ergebnisse kommen als Markdown oder CSV in den Ordner [`docs/`](docs/).
